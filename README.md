# ClinicFlow

ClinicFlow is a modern clinic management web application designed to streamline patient flow, receptionist operations, and doctor-facing workflows.

## Overview
This project provides a simple and intuitive interface for managing clinic activities, including:
- patient queue tracking
- receptionist operations
- doctor dashboard views
- display screen monitoring
- authentication and session management

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase

## Features
- User authentication
- Role-based views for doctors and reception staff
- Queue management
- Responsive interface
- Modern UI design
